# 數學 AI 學習區 Curriculum Map

更新日期：2026-06-13

## 分數料理台

| 項目 | 內容 |
|---|---|
| 適用年級 | P3-P4 |
| 主題 | 分數大小、等值分數、分子分母意義 |
| 學習目標 | 學生能用視覺模型表示目標分數，並說明等值分數為何一樣大 |
| 核心操作 | 選分母、調分子、比較目標分數、檢查答案 |
| 即時回饋 | 正確時顯示最簡分數；錯誤時顯示交叉乘積提示 |

## 常見錯誤與工具介入

| 常見錯誤 | 工具介入 |
|---|---|
| 以為分母越大，分數一定越大 | 讓學生比較 1/2、3/6、4/8 的面積 |
| 只看分子，不看整體平均份數 | 分數盤同時顯示切成幾份與取幾份 |
| 不理解等值分數 | 挑戰要求用不同分母切出同一大小 |
| 背交叉相乘但不明意思 | 錯誤提示連回圖像與乘積比較 |

## 與教學的連結

- 適用年級：P3-P4
- 適用科目：數學
- 建議堂數：5-10 分鐘作課堂引入或小組 station
- 差異化調整：弱學生先用同分母挑戰；高能力學生要找兩個等值分數並口頭解釋
- 在美教學適配：可改用 pizza、waffle、measuring cup 等生活情境，但保留香港課程分數語言
