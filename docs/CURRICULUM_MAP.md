# 數學 AI 學習區 Curriculum Map

更新日期：2026-06-13

## 分數料理台

| 項目 | 內容 |
|---|---|
| 適用年級 | P3-P4 |
| 主題 | 分數大小、等值分數、分子分母意義 |
| 學習目標 | 學生能用視覺模型表示目標分數，並說明等值分數為何一樣大 |
| 核心操作 | 選分母、調分子、比較目標分數、檢查答案 |
| 即時回饋 | 正確時顯示最簡分數；錯誤時顯示交叉乘積提示 |

## 體積建築師

| 項目 | 內容 |
|---|---|
| 適用年級 | P5 |
| 主題 | 體積、立方厘米、長方體、一層數量 × 層數、缺口修正、1000 cm³ = 1 L |
| 學習目標 | 學生能用 1 cm³ 方塊建立立體，從數方塊過渡到使用長 × 闊 × 高，並能處理缺口與單位量感 |
| 核心操作 | 調整長、闊、高、移走方塊、切換立體／分層／缺口視圖、檢查體積 |
| 即時回饋 | 正確時顯示完整算式；錯誤時提示學生先數底層、再看層數，或用完整長方體減去缺口 |

## 常見錯誤與工具介入

| 常見錯誤 | 工具介入 |
|---|---|
| 以為分母越大，分數一定越大 | 讓學生比較 1/2、3/6、4/8 的面積 |
| 只看分子，不看整體平均份數 | 分數盤同時顯示切成幾份與取幾份 |
| 不理解等值分數 | 挑戰要求用不同分母切出同一大小 |
| 背交叉相乘但不明意思 | 錯誤提示連回圖像與乘積比較 |
| 只數看得見的表面，沒有理解體積是佔用空間 | 體積建築師用 1 cm³ 方塊建立可見立體，讓學生看到每一層都有方塊 |
| 混淆 cm、cm²、cm³ | 計算列分開顯示長、闊、高、底面一層數量與總體積 |
| 忘記把一層數量乘以層數 | 分層觀察模式把「長 × 闊」與「層數」放在同一操作流程 |
| 有缺口時仍用完整長方體答案 | 缺口任務要求先建立 4 × 3 × 2，再移走 4 個方塊，回饋句連到 24 − 4 |
| 以為形狀不同，體積一定不同 | 同體積任務要求學生找出不同長闊高但同為 12 cm³ 的模型 |
| 把「圍欄」題當作面積題 | 面積周界診斷室要求先選「周界」，再看四條邊總長 |
| 把「鋪滿」題當作周界題 | 面積周界診斷室用方格模型顯示覆蓋格數是面積 |
| 以為同一面積一定同一周界 | 同面積不同形狀任務要求學生換形狀比較 |
| 固定周界時不知道如何找最大面積 | 固定周界任務引導學生由 1 × 9 比較到 5 × 5 |

## 與教學的連結

- 適用年級：P3-P4
- 適用科目：數學
- 建議堂數：5-10 分鐘作課堂引入或小組 station
- 差異化調整：弱學生先用同分母挑戰；高能力學生要找兩個等值分數並口頭解釋
- 在美教學適配：可改用 pizza、waffle、measuring cup 等生活情境，但保留香港課程分數語言

## 體積建築師與教學的連結

- 適用年級：P5
- 適用科目：數學
- 建議堂數：5-10 分鐘作課堂引入、小組 station 或課後鞏固
- 差異化調整：弱學生先完成 1 cm³、4 × 3 × 2；高能力學生挑戰同體積不同形狀與缺口修正，並口頭解釋算式
- 在美教學適配：可連到美國常見的 1 L 飲品、storage bin、cubic inch 對照，但仍保留香港課程的 cm³ 與 L 轉換

## 面積周界診斷室

| 項目 | 內容 |
|---|---|
| 適用年級 | P4-P5 |
| 主題 | 面積、周界、長方形、正方形、文字題量度判斷 |
| 學習目標 | 學生能分辨「鋪滿」與「圍邊」，並能根據情境選擇面積或周界公式 |
| 核心操作 | 調整長闊、選擇面積或周界、比較目標、檢查答案 |
| 即時回饋 | 錯用面積或周界時，直接提示「鋪滿」或「圍邊」的語境線索 |

## 面積周界診斷室與教學的連結

- 適用年級：P4-P5
- 適用科目：數學
- 建議堂數：5-10 分鐘作課堂引入、小組 station、功課後錯因補救
- 差異化調整：基礎學生先做圍欄與鋪地磚兩題；高能力學生挑戰同面積不同周界及固定周界最大面積
- 在美教學適配：可把情境換成 fence、garden bed、floor tile、poster frame 等美國校園與家居生活例子，同時保留香港課程的 cm、cm²、周界、面積用語
