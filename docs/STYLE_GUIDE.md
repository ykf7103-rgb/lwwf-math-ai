# 數學 AI 學習區 Style Guide

更新日期：2026-06-13

## 視覺方向

- 保留數學主站明亮、兒童友善的風格，但工具頁要比首頁更專注。
- 使用真實 LWWF 校章與校園背景作品牌信號。
- 分數料理台使用分數盤作主要視覺，不用純文字題。
- 體積建築師使用等角方塊 canvas 作主要視覺，不用靜態圖片或純算式。
- 色彩避免單一藍色主題，混合 teal、blue、coral、gold、green。

## 互動控制

| 控制 | 用法 |
|---|---|
| segmented buttons | 分母選擇 |
| view mode buttons | 體積建築師的立體模型、分層觀察、補回缺口視圖 |
| stepper | 分子加減 |
| slice buttons | 直接選取取幾份 |
| range sliders | 體積建築師的長、闊、高、移走方塊 |
| primary button | 檢查分數 |
| secondary buttons | 下一題、重設 |
| status pills | 完成度、準確率 |
| mission list | 顯示任務章、當前任務與已完成狀態 |

## 響應式要求

- 390px 手機寬度不可橫向溢出。
- 分數盤、目標盤、控制列在窄螢幕需直排。
- 體積 canvas 在桌面使用寬版，在平板與手機縮短高度並保持非空、可讀。
- 體積計算卡在手機改為兩欄，避免 `cm³` 與算式擠出容器。
- 文字不可壓出按鈕或覆蓋下一區。
- 按鈕高度至少 44px，方便小學生觸控。

## 可讀性

- 工具第一屏就是可操作區，不建立宣傳式 landing page。
- 教師提示放在旁邊或下方，不阻礙學生完成任務。
- 回饋句要指出數學原因，例如交叉乘積或最簡分數，不只顯示對錯。
- 體積回饋句要指出「一層數量 × 層數」或「完整長方體 − 缺口」，不只顯示答案。
- 學生頁不顯示 AI 供應商、proxy 或技術設定；debug 只留給教師或開發檢查。
